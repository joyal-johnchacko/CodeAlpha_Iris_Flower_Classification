# 🌸 Iris Flower Classification using Machine Learning

## 📌 Project Overview
This project focuses on building a machine learning model to classify Iris flowers into three species: Setosa, Versicolor, and Virginica based on their physical measurements. It is a supervised learning classification problem using the well-known Iris dataset.

---

## 🎯 Objective
The main objective of this project is to accurately predict the species of an Iris flower using features such as sepal length, sepal width, petal length, and petal width, and to understand the complete machine learning workflow.

---

## 🧠 Approach
- The Iris dataset was used as the input data.
- Data was split into training and testing sets.
- A Logistic Regression model was chosen for classification.
- The model was trained on the training dataset and tested on unseen data.
- Performance was evaluated using standard classification metrics.

---

## 📊 Model Evaluation
The performance of the model was analyzed using:
- Confusion Matrix (to visualize correct and incorrect predictions)
- Accuracy Score (to measure overall correctness)
- Classification Report (to evaluate precision, recall, and F1-score)

The model achieved high accuracy and performed well across all three classes.
